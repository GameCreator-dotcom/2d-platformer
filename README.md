# 2D Platformer

A small browser platformer built with HTML, CSS, and the Canvas API. Move and jump between platforms, and try not to fall.

## Run the Game

Open `index.html` in a web browser. No installation or build step is required.

## Controls

| Action | Keys |
| --- | --- |
| Move left | A or Left Arrow |
| Move right | D or Right Arrow |
| Jump | W, Up Arrow, or Space |
| Retry or restart | R (after falling) |

## Lives and Restarts

You can fall twice and press **R** to retry from the starting platform. On the third fall, the game shows **GAME OVER**. Press **R** to start a fresh run and reset the death count.

## Project Files

- `index.html` contains the game page and canvas.
- `style.css` styles the page.
- `game.js` handles player movement, platform collisions, and drawing the game.
